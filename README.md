\# 代替发送消息 (astrbot\_plugin\_send\_text)



AstrBot 的轻量级实用插件，提供纯文本代发与跨平台的双向消息监视功能。

此插件由AI辅助生成。



\## ✨ 支持平台列表

\- QQ官方机器人

\- 个人微信

\- KOOK

\- Discord



\## 🚀 功能一：代替发送文本

\*\*权限要求\*\*：仅 AstrBot 管理员

\*\*使用方法\*\*：在会话内 `@机器人`，然后输入指令：

`/发送文本 你需要发送的内容`

\*\*效果\*\*：机器人会直接把你输入的文字原样回复出来（被动回复，无需开启主动发言）。



\## 🕵️ 功能二：双向消息监视

\*\*权限要求\*\*：仅 AstrBot 管理员

\*\*使用方法\*\*：

1\. \*\*开启监视\*\*：管理员私聊机器人发送：

&#x20;  `/监视群聊消息 <目标会话UMO>`

&#x20;  \*（输入后，该目标将被设为唯一监视目标）\*

2\. \*\*关闭监视\*\*：再次发送相同的指令：

&#x20;  `/监视群聊消息 <目标会话UMO>`

&#x20;  \*（输入后，立刻停止双向转发）\*



\*\*同步逻辑\*\*：

\- 被监视会话收到\*\*纯文本\*\*消息 → 自动转发到管理员私聊。

\- 管理员在私聊直接发送\*\*纯文本\*\*消息 → 自动发送到被监视的目标会话。



\## ⚠️ 注意事项

\- \*\*单目标限制\*\*：一次只能监视一个会话。如果输入新的 UMO，会覆盖旧的监视目标。

\- \*\*纯文本限制\*\*：为保证稳定，仅转发纯文本，会自动跳过图片、语音、文件、表情等其他消息类型。

\- \*\*状态重置\*\*：监视目标仅保存在内存中，AstrBot 重启后，监视状态会自动清空，需重新指令开启。

\- \*\*平台限制\*\*：部分平台主动消息存在平台限制、限流，请合理使用主动推送功能。

\- \*\*防冲突机制\*\*：如果你在私聊发送以 `/` 开头的消息，插件会认为是指令而不会将其转发到目标会话。
